## Структура репозиторію

| Файл | Що в ньому |
|---|---|
| `README.md` | опис репозиторію |
| `lab1.md` | титулка, мета і теоретичні відомості лабораторної роботи |
| `.github/PULL_REQUEST_TEMPLATE.md` | шаблон Pull Request (Task link, What has been changed?, Important notes, Self-checks) |
| `.gitignore` | список файлів, які Git не відстежує |

## Як працювали

1. У гілці `main` створено `README.md`.
2. Створено гілку `initialize-repository` і додано в неї файли роботи.
3. Відкрито Pull Request `initialize-repository` → `main` на перевірку двом одногрупникам.
